# 写一篇博文

**写作方法论(选题 / 模板 / 自检 / 避坑)见仓库根 `AGENTS.md` 的「写作方法论」章节**——那是唯一事实源。本 skill 只管起草工作流。

## 流程

1. **捞素材**:从 `ops/log/` 或刚做的 debug,收集报错原文、试过的命令、官方文档链接。好博文来自真实过程,不是现编。
2. **选模板**:按 AGENTS.md 三套模板(拆解 / 日记 / 决策)挑一个,定骨架。
3. **起草**:基于素材出初稿,遵守下面的 momojie-home 约定。
4. **用户过一遍**:加判断、调语气、删水分——这步只有用户能做,是 ta 的声音。
5. **自检**:过 AGENTS.md 的质量清单。
6. 交 `publish` skill 发布。

## momojie-home 约定

- **路径**:`src/posts/<分类>/YYYY-MM-DD-slug.md`(分类即子目录,新建分类就建新目录)
- **frontmatter**:
  ```yaml
  ---
  title: 标题
  category:
    - 分类1
    - 分类2
  date: YYYY-MM-DD
  ---
  ```
- **摘要**:正文放 `<!-- more -->`,它之前的是列表页摘要
- **语言**:中文、第一人称、口语化
